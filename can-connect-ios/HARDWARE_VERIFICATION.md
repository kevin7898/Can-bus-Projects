# Hardware acceptance — outstanding

The simulator, loopback scanner fixture, unsigned device build and native Mac integration exercise software behavior. They do not prove real vehicle or iPhone acceptance. Build 4 (1.0.0) was development-signed, installed and launched on the connected iPhone on October 23, 2026. Existing trips, fills, vehicle IDs and selection were checked before/after the update and preserved; a local pre-update backup was retained outside Git. A physical-device UI test also passed manual make/model entry, keyboard dismissal, saving and switching back to the sample profile, using isolated test data. This confirms installation/startup and that onboarding path; it does not validate real telemetry. GPS, scanner, vehicle and phone-to-Mac LAN acceptance are still outstanding.

Use a parked vehicle for initial checks. Keep personal VINs, routes and pairing tokens outside Git and public issue logs.

1. **Install/sign:** Build 4 is installed as CAN Connect. For subsequent builds, choose your development team in Xcode and run CANConnect.xcodeproj on the iPhone. Confirm onboarding/profile persistence after relaunch. The generic unsigned Release build is a build check; only a development-signed build can be installed on the provisioned device. See IPHONE_TESTING.md.
2. **GPS:** grant location access, obtain a real fix, record movement, lock/unlock the phone, and finish. Confirm coordinates, timestamps, accuracy, gaps and recovery behavior in the exported recording. Denial/revocation should show an actionable state; a sample route is not GPS acceptance.
3. **Scanner compatibility:** join the actual Wi-Fi ELM327 network; enter its documented host/port. Verify required AT settings, prompt framing, VIN/protocol, supported PIDs and sensible standard readings with ignition/engine state. Compare units and values with a trusted scan tool. Vehicles without VIN support require manual confirmation. A mismatched VIN must block acquisition. For build 4, also test OBDLink MX+ via Bluetooth/MFi using MXPLUS.md; real accessory session and vehicle acceptance remain pending.
4. **Recording/freshness:** record several minutes, stop, relaunch, and compare raw commands/replies and timestamps with displayed readings. Turn ignition off or disconnect the scanner transport; stale readings should clear and the draft should save. Backgrounding saves/stops scanner acquisition; screen lock/background scanning is not supported. Reopen and reconnect explicitly. Verify unavailable PIDs stay blank. Validate rate/coverage before relying on calculated fuel totals.
5. **Two vehicles:** confirm separate histories/preferences, correct scanner identity and trip vehicle ID, and prevention of switching during recording. Reconnecting must identify the newly chosen vehicle.
6. **Mac LAN:** explicitly enable LAN access in the native Mac app and satisfy macOS firewall/local-network permissions. Join the same reachable private network from the phone, grant iOS local-network access, then pair using the real token. Test `.local` and private IPv4 URLs. Do not configure public exposure for this check.
7. **Transfer:** send a GPS and scanner recording. Check the Mac's original files, vehicle binding, actual values, receipt hash/bytes and processed trip. Check the phone retains its originals. Test a wrong token, unreachable Mac, interrupted upload, queued/paused processing and retry after relaunch. There should be one Mac original/receipt for identical retries; a queued receipt must not display completion. Scanner Wi-Fi commonly lacks access to the home Mac; switch networks after recording.
8. **Resource behavior:** measure scanner latency, battery/heat, larger recording checkpoints and upload duration. Test the 100,000-response session limit, failed storage and large libraries on the physical phone before extended use.

Still outside this build: BLE, other MFi adapters, USB, raw CAN, manufacturer DPF/UDS signals, simultaneous GPS+OBD acquisition, automatic background uploads, kWh/charging logging, TestFlight/App Store distribution, and any public server deployment.
