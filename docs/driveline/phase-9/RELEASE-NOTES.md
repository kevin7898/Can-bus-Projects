# DriveLine 1.0.0 (25) automated candidate

DriveLine now includes an evidence-preserving performance layer for large libraries and signal traces, a sanitized million-observation regression corpus, cross-platform operation signposts, display-only gap-aware chart reduction, complete Swift concurrency cleanup, privacy manifests, and archiveable Mac/iPhone Release configurations.

This candidate also corrects two issues found during private physical observation. The Record screen now distinguishes location-session connectivity from observation freshness, so a stopped vehicle does not falsely appear to lose GPS; stale speed remains unavailable and no location evidence is invented. Initial acquisition, weak fixes and unavailable service have honest separate states with a dedicated GPS retry. Journey detail now prepares large signal series outside the main actor, reducing the temporary stall when selecting telemetry-rich trips.

This candidate preserves schema-1/schema-2 archives, stable vehicle/recording/fill identities, exact originals and hashes, external receipt storage, annotations, scanner settings, pairing data, appearance preferences and queued transfers. Debug performance fixtures are sample-labelled and excluded from real totals.

Automated shared, Mac, API, iPhone unit/UI, compact accessibility, static-analysis and unsigned archive gates pass. Physical iPhone/Jetta/scanner/LAN/Live Activity qualification and signed distribution validation remain required.
