# Local telemetry and trip logs, version 1

Header bytes: `44 4C 54 4C 01 00 00 00` (DLTL, version 1). Each frame: unsigned 32-bit big-endian JSON body length; unsigned byte type; UTF-8 JSON body; unsigned 32-bit big-endian IEEE CRC32 over type + body. Maximum body: 1 MiB, checked before allocation. No GPS is present in committed fixtures.

Types: 0 session header, 1 sanitized exchange, 2 acquisition event; 10 legacy-compatible trip metadata checkpoint, 11 decoded sample, 12 accepted GPS observation. Session header includes recording/session ID, opaque vehicle ID, parser/policy versions and clock epoch. Exchanges retain monotonic times, wall mapping, sequence, generation and redacted request/reply evidence. Samples retain ECU, clock epoch, monotonic receipt time and exchange ID. GPS observations are appended independently; metadata checkpoints omit sample and route arrays.

Session logs: one awaited write at a time, one-second sync interval plus lifecycle sync, SHA-256/length/count finalize marker. Trip sample writer: at most 128 queued jobs; live draft keeps at most 256 recent samples and constant-memory integration. Queue admission is not durability. Sync occurs after an append when one second has elapsed, at checkpoints and Finish. Between samples, an unsynced final tail can remain until the next checkpoint/lifecycle flush; the app checkpoint remains five seconds. No claim of one-second wall-clock durability during inactivity.

Finish materializes the legacy trip once off the main actor, syncs the log, writes a finalize marker, then saves the trip index. Relaunch scans logs not already indexed; recording IDs deduplicate recovery. After the index save, a separate indexed receipt prevents intentional trip deletion from resurrecting raw logs on relaunch. A finalized but unindexed log is replayable. Recovery reads a maximum one-frame body at a time and accepts the exact CRC-valid prefix; it does not truncate or repair original bytes. Full legacy trip materialization is still necessary for the existing importer/archive contract.

The live map preview is bounded to 4096 observed points and thins older geometry when full; every accepted source point remains in the log. No coordinates are synthesized. At Finish the full route is restored for analysis/export. This necessary long-trip presentation difference needs on-device review; very sparse preview segments retain the existing no-gap-bridging rule. Final legacy envelope and history still retain arrays by the existing archive contract; bounded-memory claims apply to active acquisition, not export/history.
